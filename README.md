# Student Management System

A Python-based Student Management System built using Object-Oriented Programming.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- JSON Data Storage
- File Handling
- Exception Handling
- Input Validation

## Technologies

- Python
- OOP
- JSON
- File Handling

## How to Run

Run:

python main.py

## Project Purpose

This project was developed to practice Python, OOP, JSON data handling, file handling and exception handling.
